# PROJECT BRIEF:

A real estate business in Bengaluru collects leads everyday. People fill a form on the website, message on facebook, instagram, whatsapp, coming through Google/meta ads, or refereed by someone. All of these leads end up in one place which could be Google sheet which will be maintained by the Real estate business

# WHAT WE ARE BUILDING:

An Agent which can have the entire conversation with a lead on Whatsapp just like Human interacts. It will be completely conversation driven and not a menu system where the person presses buttons on Whatsapp. The Agent should be able to respond in multiple Indian languages like Hindi, English, Kannada, Tamil, Konkani and it should sound authentic and just how real conversations are in these language and not look artificial. 

The business keeps its leads in a simple spreadsheet on Google sheet. The agent should first greet the user by name and reminds them they had enquired about a property. If they say yes, they are still looking, it asks three things: What kind of Property they are looking, what budget and in which area. If the user says no, then end gracefully by a message and don’t message the user again so that there is no spamming.

After this when user replies with yes then the agent should send something like this- 3 BHK, Around 2 crore, Bengaluru- mysuru Expressway.

The agent then shows all the properties listed in that particular area for example 5 listing that fit the user/client requirement from the last message. This message of listing should be in the form of numbered list with prices. 

Then the user/client will pick one or more of those listing just by replying with the number of that listing or the name. Then agent should send the key details of that property with bullet points and along with send hero image of that property. This is the  most important one and it is deliberate as sending 8-10 photos at once looks pushed/spam the user. Sending one and send a short message that asks the user if they would like to see more photos, they can reply with yes and also asking them for the video as well so that we maintain a real effective conversation just like how pro sales people do.

After that the rest of the photos or video to be sent by the agent on the consent of the user.
Post this the agent should be looking for what the user responds. May be he wants to more details of the property or any other question, the agent should respond accordingly and agent should also give a nudge at the right time when it seems that user is interested - it can ask the user if they would like to book a site visit for the property. If the user says yes to the booking request, agent should take the booking and then reply to the user about date and time slot preference. On understanding that the agent should take the booking and confirm to the user that Booking confirm and along with that send a Google maps link.

# What the agent should not do:

It should never make a property, a price or a detail. Everything is says about a listing comes from the business’s own data. If it does not  know something it says so.

It should never behave like a broadcast system, blasing the same message to everyone at once. It works one conversation at a time and it responds to what the person actually said. 

It should never push. If someone says the budget is high or the location does not suit them, then the answer is to offer something else and not to repeat the pitch.

It should never pretend a booking is confirmed when it is not. A site visit is only confirmed once it has been properly recorded
